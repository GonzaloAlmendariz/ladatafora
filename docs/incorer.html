IncoreR

El INCORE del IPE, desde R.

IncoreR carga las bases oficiales del Índice de Competitividad Regional y genera tablas, mapas y radares listos para usar. Para quienes no usan R, el complemento IncoreR Web hace lo mismo con sliders y menús.

Qué hace

Seis tipos de gráfico

01

Distribución

Histogramas, densidades y boxplots de puntajes por pilar e indicador.

02

Comparación entre regiones

Barras y líneas con intervalos, con opción de contrastar contra un promedio nacional.

03

Mapas

Coropletas por región con escalas de color pensadas para informes impresos.

04

Radar

Perfiles comparativos de los seis pilares del INCORE para varias regiones.

05

Series temporales

Evolución del índice o de un indicador específico a lo largo de las ediciones.

06

Rankings

Tablas ordenadas y formateadas, exportables a Word o PDF con Quarto.

IncoreR Web

La versión sin código

El mismo paquete detrás, con una interfaz Shiny para quienes no programan.

Consultas puntajes e indicadores de cualquier edición del INCORE, filtras por región, pilar o indicador, y obtienes el gráfico en segundos.

Los gráficos se descargan en alta resolución (PNG, PDF, SVG) y se pueden usar directamente en informes, tesis o presentaciones.

En código

Cómo se usa

Tres funciones, básicamente.

Cargas una edición del INCORE con incore_leer(), eliges el pilar o indicador, y llamas a la función graficar_* que necesites. Cada una acepta ajustes de tema, escala y anotaciones.

  • incore_leer() · incore_pilar()
  • graficar_ranking() · graficar_mapa()
  • graficar_radar() · graficar_serie()
  • tema_incore() — presets tipográficos
R · incorer.R2025
# Cargar IncoreR y visualizar pilares
library(incorer)

datos <- incore_leer(edicion = "2025")

# Ranking del pilar Instituciones
graficar_ranking(
  datos,
  pilar = "Instituciones",
  destacar = "Lima"
)

# Mapa regional con coropleta
graficar_mapa(
  datos,
  indicador = "Educacion",
  paleta = "viridis"
)

# Radar comparativo por región
graficar_radar(
  datos,
  regiones = c("Arequipa", "Cusco", "Piura")
)

Preguntas

Dudas frecuentes

¿Qué es el INCORE?

El Índice de Competitividad Regional (INCORE) es elaborado anualmente por el Instituto Peruano de Economía (IPE). Evalúa la competitividad de las 24 regiones del Perú a través de seis pilares: Entorno Económico, Infraestructura, Salud, Educación, Laboral e Instituciones. IncoreR consume directamente estas bases públicas.

¿Necesito programar en R para usar los gráficos?

No necesariamente. IncoreR Web (la app Shiny) habilita todas las visualizaciones sin escribir código. Si ya usas R, el paquete te da control total sobre el tema, escalas, anotaciones y exportación.

¿Puedo descargar los gráficos en alta calidad?

Sí. Tanto desde el paquete como desde la app web puedes exportar los gráficos en PNG, PDF o SVG con resolución adecuada para informes, tesis o presentaciones institucionales.

¿El paquete se actualiza con cada nueva edición del INCORE?

Sí. Cada edición nueva del INCORE se incorpora al paquete y a la app web, manteniendo compatibilidad con ediciones anteriores para series históricas y comparaciones temporales.
